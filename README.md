# xmas-2026 · 손동작 크리스마스 (PD팀 연말 메시지)

**바로 보기:** https://asnas86-zion.github.io/xmas-2026/

> 개인 작업 저장소 [yh-work](https://github.com/asnas86-zion/yh-work)의 `experiments/project-02-xmas-gesture`를 공개 배포용으로 옮긴 것입니다.

> 상태: 1차 버전 완성 · 다듬는 중

웹캠에 손을 보여주면 손가락 개수에 따라 빛나는 입자들이 혜성처럼 흩어졌다가 크리스마스 모양으로 다시 모입니다.
레퍼런스 영상(인스타그램 릴스)의 흐름과 그래픽 스타일을 따라 만든 비상업용 팀 메시지입니다.

| 손동작 | 장면 |
| --- | --- |
| 손 없음 | 하얀 혜성 꼬리가 화면을 휘감음 |
| ☝️ 1개 | 눈사람 |
| ✌️ 2개 | 크리스마스 트리 |
| 3개 | 루돌프 |
| 4개 | 선물상자 (입체 회전) |
| 🖐 5개 | 눈송이 |
| ✊ 주먹 | 산타 썰매 + "Merry Christmas" + 팀 메시지 |

## 실행 방법

카메라는 `https://` 또는 `localhost` 에서만 켜집니다. 파일을 더블클릭(file://)하면 동작하지 않아요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages(Settings → Pages → `main` / `/ (root)`)로 배포되어 위 링크로 열립니다.

### 처음 시작하면

화면 아래 안내가 순서대로 나와요: 손가락 1개 → 2개 → 3개 → 4개 → 5개 → 주먹.
모양이 완성될 때마다 다음 단계로 넘어가고, 마지막엔 산타 썰매와 팀 메시지가 나타나요.
손을 좌우·위아래로 움직이면 그래픽도 따라 움직여요. 배경에는 오르골 'Jingle Bells'가 흘러나와요.

### 조작

- **카메라로 시작**: 손가락 개수로 장면 전환
- **카메라 없이 보기**: 숫자키 `0`~`5`, 또는 화면 아래 버튼 (마우스를 움직이면 보임)
- `i` 혜성으로 돌아가기 · `g` 가이드 다시 시작 · `m` 음악 켜기/끄기 (오른쪽 위 ♪ 버튼도 가능)
- `c` 카메라 미리보기 숨기기 · `h` 안내 숨기기 · `f` 전체화면

## 수정하기

- 문구, 가이드 문구, 음악, 손 따라가기 정도, 손동작↔장면 매핑, 입자 개수, 전환 속도: [`config.js`](config.js)
- 음악(오르골 연주): [`music.js`](music.js). 다른 곡을 쓰려면 mp3를 폴더에 넣고 `config.js`의 `music.file`에 파일 이름을 적어 주세요 (사용 권리가 있는 음원만)
- 각 모양(색·형태): [`shapes.js`](shapes.js)
- 입자 움직임·혜성 궤적·글로우: [`main.js`](main.js)
- 손가락 세기 로직: [`gesture.js`](gesture.js)

## 사용 기술

- [three.js](https://threejs.org/) 입자 렌더링 + 블룸(글로우)
- [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker) 손 인식 (브라우저 안에서만 처리, 영상은 어디에도 전송되지 않음)
- 모든 라이브러리는 CDN에서 불러오므로 빌드 과정 없음
